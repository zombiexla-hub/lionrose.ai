// Overview
Valuation Verification Agent · In Development

See the risk you actually hold.

Some public funds report values that look far smoother than the assets behind them. The Valuation Verification Agent runs independent tests on whether a fund's reported value moves the way reality does.

It gives trustees and investors a plain read on understated risk, so the number on the statement can be checked against the market it claims to reflect.
